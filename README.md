# Dashboard รายงานผลคุณภาพน้ำประปา เส้นท่อจ่ายน้ำ (รายวัน)

หน้าเว็บนี้ดึงข้อมูลจาก Google Sheet แบบสดทุกครั้งที่เปิดหน้า และมีปุ่ม **"บันทึกรูป / ส่ง LINE"** สำหรับ export เป็นรูป PNG
(บนมือถือจะเปิดเมนูแชร์ เลือก LINE ได้ทันที บนคอมพิวเตอร์จะดาวน์โหลดไฟล์รูป)

## ไฟล์
| ไฟล์ | หน้าที่ |
|---|---|
| `index.html` | หน้า dashboard ทั้งหมด (ตั้งค่าอยู่ใน `CONFIG` ด้านบนไฟล์) |
| `lib/html2canvas.min.js` | ไลบรารีแปลงหน้าเว็บเป็นรูป |
| `sample.csv` | ข้อมูลตัวอย่าง เปิดทดสอบได้ด้วย `index.html?csv=sample.csv` |
| `logo.png` | โลโก้หน่วยงาน (มุมซ้ายบน) |
| `header-bg.jpg` | ภาพพื้นหลังส่วนหัว (วิวเมือง/โรงผลิตน้ำ) — เปลี่ยนรูปได้โดยใช้ชื่อไฟล์เดิม ขนาดแนะนำ 2245×362 |

## ขึ้น GitHub Pages
1. สร้าง repository ใหม่บน GitHub แล้วอัปโหลดไฟล์ทั้งหมดในโฟลเดอร์นี้ (รวมโฟลเดอร์ `lib`)
2. ไปที่ **Settings → Pages → Build and deployment** แล้วเลือก Source = *Deploy from a branch*, Branch = `main` / `(root)` แล้วกด Save
3. รอประมาณ 1 นาที จะได้ลิงก์ `https://<ชื่อผู้ใช้>.github.io/<ชื่อ repo>/`

## ตั้งค่า Google Sheet
- ชีตต้องแชร์เป็น **"ทุกคนที่มีลิงก์ → ผู้มีสิทธิ์อ่าน"** (หน้าเว็บอ่านข้อมูลผ่าน Google Visualization API)
- **แนะนำ (เสถียรกว่า):** ไฟล์ → แชร์ → **เผยแพร่ไปยังเว็บ** → เลือกแท็บ `ชีต1` → รูปแบบ **CSV** → คัดลอกลิงก์มาใส่ที่ `CONFIG.CSV_URL` ใน `index.html`
- หัวคอลัมน์ที่ใช้: `อันดับที่, สถานที่, ถนน, วันที่เก็บ, เวลา, สาขา, คลอรีนอิสระคงเหลือ, ความขุ่น, ความเป็นกรด-ด่าง, การนำไฟฟ้า, สารละลายทั้งหมด, รับน้ำจาก`
- คอลัมน์ **คลอไรด์** (หัวคอลัมน์มีคำว่า "คลอไรด์") จะแสดงในตารางเฉพาะวันที่/สาขาที่มีค่าอย่างน้อย 1 แถว ถ้าไม่มีค่าเลยจะซ่อนอัตโนมัติ
- คอลัมน์สุดท้ายของตารางคือ **รับน้ำจาก** (เปลี่ยนได้ที่ `CONFIG.LAST_COLUMN`) ส่วน **สาขา** ใช้สำหรับตัวกรองด้านบน
  (ลำดับคอลัมน์ไม่สำคัญ แต่ชื่อหัวคอลัมน์ต้องคงไว้)
- วันที่รับได้ทั้ง `02/11/2026` และ `2/11/2569` (พ.ศ.) หน้าเว็บจะแสดงเป็น พ.ศ.

## การใช้งาน
- เลือก **วันที่** (ค่าเริ่มต้นคือวันล่าสุดในชีต), กรอง **สาขา**, เลือกการ **เรียงลำดับ**
- ลิงก์ตรงไปยังวันที่ที่ต้องการได้ เช่น `...?date=2026-11-02`
- ช่องสีแดง = ไม่ผ่านเกณฑ์มาตรฐาน, ช่องสีเหลือง = แจ้งเตือน

## เกณฑ์ที่ใช้
| รายการ | หน่วย | มาตรฐาน |
|---|---|---|
| คลอรีนอิสระคงเหลือ | mg/l | 0.2 – 2.0 |
| สีปรากฏ | แพลทินัม-โคบอลต์ | ไม่เกิน 15 |
| ความขุ่น | NTU | ไม่เกิน 1.0 |
| ความเป็นกรด-ด่าง | – | 6.5 – 8.5 |
| การนำไฟฟ้า | µS/cm | ไม่มีเกณฑ์กำหนด |
| สารละลายทั้งหมด | mg/l | ไม่เกิน 1,000 |
| คลอไรด์ (แสดงเมื่อมีค่า) | mg/l | ไม่เกิน 250 |

ตัวอย่างที่มีค่าใดค่าหนึ่งไม่ผ่าน จะนับเป็น "ไม่ผ่านเกณฑ์" และช่องนั้นเป็นสีแดง
แจ้งเตือน (สีเหลือง): คลอรีน 0.20 – 0.30 mg/l

## สเกลกราฟวงกลม
| คลอรีน (mg/l) | ความขุ่น (NTU) | ความนำไฟฟ้า (µS/cm) |
|---|---|---|
| 🟨 < 0.20 | 🟩 0–0.5 | 🟩 < 400 |
| 🟩 ≥ 0.20 | 🟦 > 0.5–1.0 | 🟦 400–500 |
| | 🟨 > 1.0–2.0 | 🟨 > 500–700 |
| | 🟧 > 2.0–4.0 | 🟧 > 700–1,200 |
| | 🟥 > 4.0 | 🟥 > 1,200 |

สเกลกราฟแยกจากเกณฑ์ผ่าน/ไม่ผ่าน (แก้สเกลได้ในฟังก์ชัน `render()` ส่วน `bucket(...)`)

ปรับตัวเลขได้ที่ `CONFIG.STD` และ `CONFIG.WARN` บนสุดของ `index.html` (ใส่ `null` เพื่อปิดรายการนั้น)
